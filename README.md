# 生涯排排樂

心理系生涯講座的互動活動。學生用手機把 20 張生涯詞卡分類並命名，講者在投影幕上即時看到全場的彙整結果，最後再和王秀槐、陳珍德（2019）的臺灣大學生生涯概念原型研究對照。

- **學生頁**：掃 QR code 進入，匿名分類，可選填暱稱，送出後可修改。
- **講者頁**：點頁面下方的「講者入口」，輸入密碼 `0214`。分 6 頁依序揭曉：參與人數（含 QR code）→ 類別命名詞雲 → 詞語共現熱圖 → 「興趣」在哪 → 新增的詞 → 論文對照。可用鍵盤左右鍵翻頁，每 5 秒自動更新。

## 檔案

| 檔案 | 用途 |
|---|---|
| `index.html` | 網頁本體（學生頁＋講者頁） |
| `config.js` | 填入 Google Apps Script 網址的地方 |
| `apps-script/Code.gs` | 貼到 Google 試算表的後端程式 |

## 一、設定 Google 試算表（約 5 分鐘）

1. 到 Google 雲端硬碟建立一個新的試算表，例如命名為「生涯排排樂資料」。
2. 在試算表上方選單點「擴充功能」→「Apps Script」。
3. 刪掉編輯器裡原本的內容，把 `apps-script/Code.gs` 的全部內容貼上，按儲存。
4. 點右上角「部署」→「新增部署作業」。
   - 類型選「網頁應用程式」
   - 執行身分：**我**
   - 具有存取權的使用者：**所有人**
5. 按「部署」。第一次會要求授權，依畫面指示允許存取（若出現「Google 尚未驗證這個應用程式」，點「進階」→「前往（不安全）」，這是你自己的程式）。
6. 複製產生的「網頁應用程式網址」（以 `https://script.google.com/macros/s/` 開頭、`/exec` 結尾）。
7. 打開 `config.js`，把網址貼進 `apiUrl: ""` 的引號裡，存檔並推上 GitHub。

> 之後如果修改了 `Code.gs`，要用「部署」→「管理部署作業」→ 編輯 → 版本選「新版本」，網址才會套用新程式。

## 二、開啟 GitHub Pages

1. 到 GitHub 上這個 repo 的 **Settings → Pages**。
2. Source 選「Deploy from a branch」，Branch 選 `main`、資料夾選 `/ (root)`，按 Save。
3. 約 1 分鐘後，頁面上方會出現網址，例如 `https://你的帳號.github.io/career-sort/`。

## 三、演講前的檢查清單

- [ ] 用自己的手機掃 QR code，完整分類並送出一次。
- [ ] 在電腦開講者頁，確認看得到那一筆資料。
- [ ] 試算表的 `responses` 工作表有出現資料。
- [ ] 按「清空所有資料」把測試資料清掉。
- [ ] 投影時把講者頁停在第 1 頁（QR code），讓大家掃描。

## 示範模式

`config.js` 的網址留白時，網頁會進入示範模式：資料只存在目前這台裝置，講者頁多一個「加入 15 筆模擬資料」按鈕，方便在設定後端前先試玩、排練講解流程。

## 備註

- 講者密碼寫在 `Code.gs` 的 `PASSWORD` 與 `index.html` 的示範模式中，只是避免學生誤入講者頁，不是嚴格的安全機制。要更改密碼，兩處都要改。
- 資料會留在你的 Google 試算表，可以下載做後續分析（`data` 欄是每個人的分類 JSON）。
- 詞卡與四面向比例出自：王秀槐、陳珍德（2019）。問世間「生涯」為何物？臺灣大學生生涯概念原型分析研究。*教育科學研究期刊，64*（2），39-68。https://doi.org/10.6209/JORIES.201906_64(2).0002
